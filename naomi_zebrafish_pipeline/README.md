# Карта плотности → NAOMi → изображения и маски

Этот пайплайн принимает статический PNG/TIFF/JPEG или многостраничный TIFF, строит **эвристическую** карту вероятности размещения нейронов и создаёт статические изображения NAOMi вместе с масками сгенерированных ядер. Размер выхода совпадает с размером входного кадра. Поддерживаются 8- и 16-битные серые изображения, а также цветные изображения, которые переводятся в яркость. Входное изображение должно быть не меньше 16 пикселей по каждой оси и не больше 12 млн пикселей целиком.

Карта **не является измеренной плотностью нейронов**: яркость на одном кадре зависит также от активности, фона и оптики. На изображениях с ярким контуром алгоритм может принять его за область с клетками. Для другого поля зрения карту нужно визуально проверить.

## Установка

Нужны Python 3.10+, GNU Octave, `mkoctfile`, компилятор C++ и пакеты Octave `image`, `statistics`, `signal` (для современных версий `statistics` также `datatypes`).

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
octave --quiet --eval 'pkg install -forge datatypes'
octave --quiet --eval 'pkg install -forge image'
octave --quiet --eval 'pkg install -forge signal'
octave --quiet --eval 'pkg install -forge statistics'
python pipeline.py build
```

Пакеты Octave достаточно установить один раз. `build` компилирует два MEX-модуля на текущем компьютере; готовые бинарные файлы не входят в Git.

## Запуск

Для изображения с известным размером пикселя **0,576 мкм**:

```bash
python pipeline.py all \
  --input /путь/к/кадру.png \
  --pixel-size-um 0.576 \
  --output outputs \
  --count 1 --start-seed 20264018
```

`--pixel-size-um` определяет физический размер моделируемого поля. Если его не указать, используется 0,875 мкм/пиксель как приближение для прежнего Zenodo-профиля. **По самому изображению физический размер пикселя определить нельзя.** По умолчанию число клеток выбирается по площади оценённой ткани:

```text
N = round(12000 × A / 104437.375),
A = число ненулевых пикселей карты × (размер пикселя в мкм)².
```

104437,375 мкм² — площадь карты, подготовленной из Zenodo TIFF при 0,875 мкм/пиксель. Поэтому для этого файла автоматический режим выдаёт 12 000 клеток. Для нового поля зрения это **начальная эвристика**, а не измеренное число биологических нейронов. Ошибки маски ткани, размер пикселя и различия в локальной плотности напрямую влияют на оценку. В `density_metadata.json` сохраняются площадь и предложенное число клеток. Явное `--cells 4000` отключает автоматический расчёт.

Для [публичной записи Zenodo 6293696](https://zenodo.org/records/6293696) (485 × 400, 16 бит) сохранён исходный проверенный рецепт карты и генерации:

```bash
python pipeline.py all \
  --input /путь/к/01_ZebrafishMul_GCaMP6s_485x400x9800_highSNR.tif \
  --output outputs --count 4 --start-seed 20263000 --workers 2
```

Если вход — TIFF-стек, карта строится по медиане 64 равномерно выбранных страниц (`--frame-count`). Если вход — один кадр, используется он один. Можно запускать этапы отдельно:

```bash
python pipeline.py prepare --input /путь/к/кадру.png --pixel-size-um 0.576 --output outputs
python pipeline.py generate --output outputs --count 4 --start-seed 20263000 --workers 2 --cells auto
```

Повторный `generate` использует сохранённую карту. Каждому компьютеру назначайте непересекающийся диапазон сидов. Если нужны другие параметры или другая карта с тем же сидом, выберите другую папку `--output`.

## Файлы результата

В папке `--output`:

- `density_base.png` — 16-битная карта вероятности размещения, в размере входного изображения;
- `density_metadata.json` — размер кадра, размер нативной сетки NAOMi, физический размер пикселя и способ построения;
- `priors/seedN.png` — вариант карты для конкретного сида;
- `samples/seedN/noisy.png` и `clean.png` — изображения NAOMi;
- `samples/seedN/semantic_mask.png` — бинарная маска всех ядер;
- `samples/seedN/instance_ids.png` — 16-битная маска с ID клетки, фон 0;
- `samples/seedN/all_instance_footprints.npz` — полные маски отдельных клеток с сохранением пересечений;
- `samples/seedN/centers_yx_px.csv` и `metadata.json` — центры и параметры кадра;
- `raw/seedN/octave.log` — журнал генерации. Большие промежуточные массивы удаляются после успешного кадра.

В NPZ `offsets` задаёт границы клеток в `pixel_index`: для ID `k` (начиная с 1) пиксели клетки — `pixel_index[offsets[k-1]:offsets[k]]`, линейные индексы растра `shape_yx`. PNG `instance_ids.png` хранит только один ID в каждом пикселе, поэтому при наложении ядер полная информация остаётся в NPZ. Маски относятся к **сгенерированным ядрам до оптического размытия**, а не к реальным клеткам на входе.

## Как строится карта

Для Zenodo 485 × 400/16 бит оставлен прежний рецепт: медианный кадр, грубая маска ткани, локальные максимумы разности гауссовых размытий, сглаживание кандидатов на 5 и 14 пикселей и умеренная полоса с пониженной плотностью около строки 217 (`--band-strength 0.70`). С этой формой ввода карта совпадает с прежней версией.

Для остальных изображений порог ткани и ярких локальных максимумов рассчитывается **от процентилей самого кадра**, а масштабы фильтров меняются с `--pixel-size-um`. Полоса Zenodo автоматически выключена. Если ярких максимумов нет, алгоритм возвращает равномерную карту в оценённой области ткани. Плавное случайное поле немного меняет карту для каждого сида.

Параметры быстрого ядерного NAOMi: радиус ядра 2,28 мкм (`--nucleus-radius`; увеличение прежнего исследовательского варианта 1,9 мкм в 1,2 раза), глубина 10 мкм, excitation NA 0,6, objective NA 0,8, halo scale 0,75 и локальное свечение +10. Генерируется один кадр на сид. Сосуды, дендриты, аксоны и движение отключены. Исходники основаны на [NAOMi](https://bitbucket.org/adamshch/naomi_sim/src/master/); условия использования сохранены в [`LICENSE-NAOMi.md`](LICENSE-NAOMi.md). Реальные данные и результаты генерации в репозиторий не входят.
